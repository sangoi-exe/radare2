## Required behavior and demonstrated failures

| Boundary | Observed wrong behavior | Required correction and decisive proof |
| --- | --- | --- |
| Array bounds | Host interprets `[010]` as eight elements; bridge interprets ten. Hexadecimal bounds can lose the declared type, and a typedef-backed Grid becomes an integer pointee. Direct c2 evaluates `[1\|2+3]` as six while a C11 compiler emits five. | Evaluate admitted C integer constant expressions once at the shared type owner, using the target integer model. Equivalent decimal/octal/hex bounds and C precedence must agree through direct, nested and typedef arrays, layout, native graph and output. Keep consumer capacity checks separate from expression meaning. Reject an unsupported or invalid expression explicitly, not as a guessed value or substituted type. |
| Signature admission | `int (f)(int)` is rejected. `afs int (object)` renames the function and flag to `int` before import fails. | Resolve grouping in the correct named/abstract declaration context, preserve the established dotted and compound-return controls, and admit the signature before applying its declared name. Rejected input leaves the prior function identity and contract unchanged. |
| Opaque aggregates | `struct Opaque;` creates no host identity; its far pointer becomes a pointer to integer. | Preserve incomplete struct/union identity through host metadata and native pointer import. By-value use without a complete layout must fail clearly; pointer identity must not require a completed opaque definition. |
| Flexible members | Host admits a complete Packet prefix and an unsized tail; bridge rejects the tail and substitutes integer for Packet. | Preserve the aggregate prefix and flexible-tail declaration through import, codec and output. Do not invent a tail extent or substitute the aggregate. Ordinary sized arrays and existing explicit near/far layers retain their meaning. |
| Recursive aliases | `typedef union B BA; union A { BA *p; }; union B { union A a; unsigned long long value; };` fails A-first but succeeds B-first. | Carry identity-versus-layout context through typedefs and finish native alias clones at the existing completion boundary. Both fresh-root orders retain identity, complete layouts and correct pointer/array stride; do not remove the incomplete by-value guard. |
| Parameter-list specificity | The AST distinguishes `()` from `(void)`, but named-function Sdb/API transport discards the distinction. Both callback typedefs become the same native type. | Preserve parameter specificity separately from record existence and argument count across current producers, storage, signature APIs/renderers, native import and writeback. Missing knowledge is not evidence of fixed zero parameters; do not reconstruct erased source facts by guessing. |
| Attribute accumulation | The default c2 collector has fixed ten-element arrays and unchecked producer increments. | Use the existing host collection facilities to keep accumulation memory-safe and preserve attribute application semantics. Verify the demonstrated capacity boundary, duplicates and both existing annotation forms without a second parser or an arbitrary silent truncation. |
| Fundamental specifiers | Contradictory sequences such as `unsigned float`, `signed unsigned int`, `short double` and `long long long` are accepted and normalized into different valid native types. | Validate combinations at the shared declaration owner and reject contradictions before import. The bridge consumes the admitted meaning instead of choosing a winning flag. Existing fixed-width names and valid target fundamental types remain supported. |
